## 前言

这个系列单纯是我看到网上那些机器臂、无人机的3D仿真，想扩展一下自己的技术栈，纯粹为了试着玩的。

开始的很果断，希望不要结束得太潦草。

### 环境选择

因为没有云服务器这种高级的资源配置，所以选择了轻量级的 MuJoCo（同时这也适合进行强化学习）。

等以后有机会了，一定要学习去使用 Issac Sim！

### 初步测试

把环境与模型文件都上传到 GitHub 仓库 -- [MuJoCo](https://github.com/Lou-uo/MuJoCo)
